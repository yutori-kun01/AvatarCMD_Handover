# v3.8 — note 記事エディタの改善（バックグラウンド生成・画像モデルの指定・入力を活かした AI 執筆）

## 変更点

- **note 記事の生成をバックグラウンドで実行**
  - 執筆・画像/図解・見出し画像は `article_jobs` テーブルのジョブとして依頼し、worker が実行する（`ARTICLE_JOBS_TICK_MS` 既定 3 秒、同時実行 `ARTICLE_JOB_CONCURRENCY` 既定 2）。
  - worker が止まっているとき（心拍が 90 秒以上古い）は web のプロセスで実行する。
  - 画面を閉じたり別ページへ移っても生成は続き、戻ると結果が本文に反映される（依頼中のジョブ ID はブラウザに保存）。
  - 画像の生成中に本文を編集しても、目印の行だけが画像に置き換わる。
  - 進み具合が 30 分更新されない実行中ジョブは「中断」として失敗にする。7 日より前のジョブは消す。
- **画像生成のモデル指定を修正**
  - 既定モデルの ID を `gpt-image2.5-sunburst`（ハイフン抜けで API が受け付けない）から `gpt-image-2.5-sunburst` に修正。
  - 設定 > 画像生成 のモデルを一覧（GPT Image 2.5 Sunburst / Flare、GPT Image 2 / 1 / 1 Mini、Gemini 3 Pro Image / 2.5 Flash Image）から選べるようにし、一覧にないモデルは ID を直接入力できる。
  - 保存済みの表記ゆれ（`gpt-image2.5-sunburst`・表示名など）は読み込み時・保存時に正しい ID に直す。
  - モデル名の誤り（404 など）は「設定 > 画像生成 でモデルを選び直す」案内付きのエラーにする。
- **見出し画像（サムネイル）を 1280×670 で生成**
  - GPT Image 2 以降は用途のサイズ（1280×672 / 1280×720）で直接生成し、1280×670 に整える（切り抜きで構図が崩れない）。
  - アップロードした見出し画像も 1280×670 に切り抜く。
  - Gemini 3 系は 2K で生成して縮小する。
- **AI 執筆の入力を柔軟に**
  - 「タイトルだけ」「タイトルとテーマ」「テーマだけ」「書きかけの本文」のどれからでも書ける。
  - 入力済みの項目は活かして整え、空の項目を AI が補う。「入力済みの部分は書き換えない」を選ぶと、タイトル・テーマはそのまま、本文は前後に足す部分だけを書く。
  - 入力欄ごとに「入力済み → 活かして整える / 空 → AI が作る」を表示し、ボタンの文言も入力に合わせて変わる。
